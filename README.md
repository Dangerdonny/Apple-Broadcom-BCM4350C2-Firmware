# Apple-Broadcom-BCM4350C2-Firmware 
Apple Broadcom BCM4350C2 (present on MacbookPro 14,1) Raw Firmware Dumps extracted from MacOS Ventura
I made this Repo because I tried installing linux on my MacbookPro 14,1 but had bluetooth audio issues. While these files did not solve my issues, I'm certain that these could be useful if used by someone with more experience.
Warning for Linux Users: As of Kernel 6.x, the standard hci_uart driver does NOT support the Apple-specific OpCodes in these files (causes Error -110/Timeout). These are provided for kernel developers and reverse engineering purposes only. Use at your own risk.
